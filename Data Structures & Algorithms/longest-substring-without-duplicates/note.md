# 筆記：從滑動視窗到指標跳躍的優化思維（LeetCode 3）

## 📌 核心思維：如何從零想到最優解？
面對新題目時，不需要憑空作畫，而是透過**「特徵識別 ➔ 逐步優化 ➔ 消除痛點」**的思考框架。

### 1. 識別題目特徵
* **關鍵字：「連續子字串」** ➔ 處理連續區間，優先聯想 **雙指標 / 滑動視窗 (Sliding Window)**。
* **關鍵字：「不重複 / 出現過」** ➔ 需要快速查找歷史紀錄，優先聯想 **`set` (集合)** 或 **`dict` (雜湊表)**。

### 2. 直覺解（基本款）：雙指標 + Set
* **邏輯**：右指標 `r` 一直前進，遇到重複字元時，啟動 `while` 迴圈讓左指標 `l` 逐格前進，並沿路從 `set` 刪除字元，直到重複字元消失。
* **痛點**：如果重複字元在很前面（例如 `s = "abcdefg...a"`），`while` 迴圈必須做多次微觀迭代（刪除 `b, c, d...`），這些被刪除的字元之後遇到還要重新加回，**存在大量重複操作（做白工）**。

### 3. 最優解（精妙解）：雙指標 + Dict 索引跳躍
* **優化核心**：既然逐格移動很慢，如何讓左指標 `l` **「瞬間跳躍」**？
* **工具升級**：將 `set` 改為 `dict`（Key: 字元, Value: **最後出現的索引位置**）。
* **機制**：一遇到重複，查表得知上一個相同字元的位置，讓 `l` 直接跳到該位置的下一格。

---

## 💻 程式碼實作與效能對比

### ❌ 直覺解 (Set + while 逐格刪除)
```python
class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        left, res = 0, 0
        seen = set()
        
        for right in range(len(s)):
            # 痛點：遇到重複時，需要 while 迴圈逐一刪除
            while s[right] in seen:
                seen.remove(s[left])
                left += 1
            seen.add(s[right])
            res = max(res, right - left + 1)
        return res
```

###  最優解 (Dict + max 指標跳躍)
```python
class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        mp = {}  # 紀錄字元與其最後出現的索引
        l = 0
        res = 0

        for r in range(len(s)):
            if s[r] in mp:
                # 精妙之處：瞬間跳躍，並用 max 確保左指標不回頭
                l = max(mp[s[r]] + 1, l)
            
            mp[s[r]] = r  # 更新/紀錄當前字元的位置
            res = max(res, r - l + 1)
        return res
```

---

## 🔍 精妙細節拆解：為什麼要用 `max(mp[s[r]] + 1, l)`？

因為最優解**沒有**在過程中刪除舊字元，所以 `mp` 內會殘留「已經不在當前視窗內」的過期字元。

### 範例：`s = "abba"`
1. `r = 0, s[r] = 'a'` ➔ `mp = {'a': 0}`, `l = 0`
2. `r = 1, s[r] = 'b'` ➔ `mp = {'a': 0, 'b': 1}`, `l = 0`
3. `r = 2, s[r] = 'b'` ➔ 重複！`l` 跳到 `mp['b'] + 1 = 2`。此時 `mp = {'a': 0, 'b': 2}`
4. `r = 3, s[r] = 'a'` ➔ 重複！此時 `mp['a']` 是 `0`（已過期，因為當前視窗起點 `l` 已經是 `2`）。
   * 如果只寫 `l = mp[s[r]] + 1` ➔ `l` 會倒退回 `1`（❌ 錯誤）。
   * 使用 `max(0 + 1, 2)` ➔ `l` 保持 `2`（ 正確，成功擋住過期資訊）。

**核心結論**：`max` 機制確保了左指標**永遠不會往回倒退**，嚴格保證每個字元只會被檢視一次。
